## What's New in KATOA v1.1.0

**Homepage hero motion background** — cleaner, faster animated orbs with glass overlay card and floating island navbar.

**Full charcoal/glass design** — migrated across all 17 pages and 57 components.

**Mobile UX** — filter sheets, sticky donate bar, sat presets, safe-area padding.

**PWA** — service worker v2, offline fallback, install prompt.

**Explore** — favorites, recently viewed wishlists, pagination (12 + load more).

**Accessibility & i18n** — ConfirmDialog + toast replace native dialogs; `pageStrings` for 7 languages; focus-visible rings; aria-labels.

**Performance** — lazy-loaded routes, per-route Lucide splits, memo on hot components.

**Other** — dynamic OG meta per wishlist, wishlist item reorder (local), breadcrumbs, earnings slider on comparison, `npm run sitemap`.
