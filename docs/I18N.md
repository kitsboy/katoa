# Internationalization (i18n)

**Last updated:** 2026-08-24

KATOA uses a **self-contained** i18n system in `src/contexts/LanguageContext.tsx`. It does not depend on the Give A Bit shared `I18nProvider` (though keys could be aligned later).

---

## Languages

| Code | Language |
|------|----------|
| `en` | English (default) |
| `es` | Spanish |
| `pt` | Portuguese |
| `fr` | French |
| `de` | German |
| `ja` | Japanese |
| `zh` | Chinese |

**No Swahili (`sw`).** Do not add `sw` to `VALID_LANGUAGES` or hreflang until a real locale ships.

---

## How it works

1. **`translations`** — flat `Record<Language, Record<string, string>>` for global UI strings (nav, buttons, errors, confirm dialogs).
2. **`pageStrings`** — page-specific copy merged into each language's translations object (dashboard, wishlist, about, comparison, explore labels).
3. **`t(key)`** — lookup function from `useLanguage()` hook; returns the key if missing.
4. **`languageFlags` / `languageNames`** — display metadata for the language picker in Navbar.

```tsx
import { useLanguage } from '../contexts/LanguageContext';

const { t, language, setLanguage } = useLanguage();
return <h1>{t('nav.explore')}</h1>;
```

---

## Adding a string

1. Add the key to `translations.en` (and all 6 other language blocks).
2. For page-specific copy, add to `pageStrings.en` (and siblings) — they are spread into each language via `...pageStrings.en`.
3. Use dot-notation keys: `confirm.deleteTitle`, `error.network`, `dashboard.welcome`.

---

## Intl formatting

`SatsDisplay.tsx` uses `Intl.NumberFormat` with the active language for locale-aware number formatting.
