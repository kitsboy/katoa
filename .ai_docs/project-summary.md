# Project Summary — KATOA

**What:** Zero-fee Bitcoin creator platform (OF-style tips + wishlists without the cut).  
**Domain:** katoa.org  
**Version:** see `public/version.json`  
**Last Updated:** 2026-08-11

## One-Liner
Creators list wishlists and take Lightning tips; fans explore the map (BTC Map merchants + KATOA projects); platform never takes a fee or custody.

## Core Features
- Explore wishlists + unified map (BTC Map API merchants + creator pins)
- Wishlist gift flow, tip menu presets, favorites export pack
- Optional Nostr: NIP-05, zaps, NIP-17 DMs (opt-in, NIP-07 only)
- Creator playbook, verticals, guidelines, PWA
- i18n EN/ES/PT/FR/DE/JA/ZH

## Tech Stack
React 18 + Vite 5 + Tailwind 3 + Supabase + Leaflet + nostr-tools · Cloudflare Pages
